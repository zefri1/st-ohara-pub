# Сайт ирландского паба St. O'Hara (Кострома)

Современный минималистичный одностраничный сайт для паба **St. O'Hara** (Max O'Hara), выполненный в светлых тонах с изысканной типографикой и интерактивными элементами.

## Структура проекта

*   [index.html](file:///C:/Users/Alexey/st-ohara-pub/index.html) — разметка страницы (Hero-блок, Атмосфера, Меню с табами, Афиша, Форма бронирования, контакты и карта).
*   [style.css](file:///C:/Users/Alexey/st-ohara-pub/style.css) — стили проекта (адаптивная сетка, дизайн-система в светлых тонах, микро-анимации, оформление интерактивных элементов).
*   [app.js](file:///C:/Users/Alexey/st-ohara-pub/app.js) — логика (интерактивные табы меню, мобильная навигация, валидация и отправка формы бронирования с выводом деталей, плавная прокрутка и анимация появления элементов при скролле).
*   `assets/` — графические материалы:
    *   [logo-clean.png](file:///C:/Users/Alexey/st-ohara-pub/assets/logo-clean.png) — чистый логотип без полей (используется на веб-сайте для максимального размера).
    *   [logo.png](file:///C:/Users/Alexey/st-ohara-pub/assets/logo.png) — версия логотипа с отступами (для корректной обрезки в круг на аватаре во ВКонтакте).
    *   [outside.jpg](file:///C:/Users/Alexey/st-ohara-pub/assets/outside.jpg) — фотография паба снаружи (используется на главном экране).
    *   [inside.png](file:///C:/Users/Alexey/st-ohara-pub/assets/inside.png) — фотография интерьера паба (используется в разделе «Атмосфера»).
    *   [boxty.jpg](file:///C:/Users/Alexey/st-ohara-pub/assets/boxty.jpg) — изображение традиционных ирландских картофельных блинов боксти в разделе меню.

## Как запустить проект

1. Локальный сервер уже запущен на порту **3000**. Вы можете открыть сайт в браузере по ссылке:
   👉 **http://localhost:3000**
2. Если вы захотите запустить его вручную в будущем, перейдите в папку проекта в консоли и выполните:
   ```bash
   npx http-server -p 3000
   ```
   или просто откройте файл [index.html](file:///C:/Users/Alexey/st-ohara-pub/index.html) двойным кликом в проводнике.

## Особенности дизайна и функционала

1.  **Премиальная светлая тема (Linen & Forest Green):** вместо стандартного темного паба использованы теплые кремовые тона, глубокий лесной зеленый и благородный янтарно-золотой.
2.  **Элегантная типографика:** сочетание акцентного заголовка `Cormorant Garamond` и чистого шрифта текста `Inter`.
3.  **Интерактивное меню:** разделено на табы (Кухня / Ирландская классика / Барная карта) с плавными переходами.
4.  **Умная форма бронирования:**
    *   Запрещает бронирование на прошлые даты.
    *   При клике на «Занять столик» в афише событий, название события автоматически переносится в комментарий к брони.
    *   Имитирует отправку на сервер с красивой анимацией успеха и отчетом о бронировании.
5.  **Scroll Reveal:** плавное проявление секций и контента при прокрутке.
